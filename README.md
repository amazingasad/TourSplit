# TourSplit Pro — Android App

A Capacitor-based Android app for group travel expense tracking.

## How to Build the APK on GitHub (No Android Studio Needed)

### Step 1: Create a GitHub Repository
1. Go to [github.com](https://github.com) and log in
2. Click **"New repository"** (green button)
3. Name it: `toursplit-pro`
4. Set it to **Public** (required for free GitHub Actions)
5. Click **"Create repository"**

### Step 2: Push These Files to GitHub
After downloading this project folder, open a terminal in it and run:

```bash
git init
git add .
git commit -m "Initial TourSplit Pro Capacitor app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/toursplit-pro.git
git push -u origin main
```

> Replace `YOUR_USERNAME` with your actual GitHub username.

### Step 3: Download Your APK
1. Go to your GitHub repository
2. Click the **"Actions"** tab
3. You'll see a workflow called **"Build Android APK"** running
4. Wait for it to finish (green checkmark, ~5-10 minutes)
5. Click on the completed workflow run
6. Scroll down to **"Artifacts"** section
7. Click **"TourSplit-Pro-APK"** to download the APK
8. Extract the zip and install the `app-debug.apk` on your Android phone

### Step 4: Install the APK on Your Phone
1. Transfer `app-debug.apk` to your Android phone
2. On your phone, go to **Settings > Security > Install unknown apps**
3. Allow installation from your file manager
4. Open the APK file and install it

## What Files to Push to GitHub

Push **everything** in this folder. The `.gitignore` already excludes:
- `node_modules/` (too large, GitHub Actions installs these)
- `android/` (generated by Capacitor during build)

**Do NOT add these to GitHub** (they are auto-generated during the build).

## PDF Export

On Android, the PDF export button will:
1. Generate the PDF
2. Open Android's **Share sheet** so you can save it to Google Drive, send via WhatsApp, Gmail, etc.
3. Or save it directly to your **Documents** folder
